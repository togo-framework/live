# live — docs

AI-agent bridge (push a prompt, a live agent answers over any channel) for togo.

- **Marketplace:** https://to-go.dev/plugins/live
- **Source:** https://github.com/togo-framework/live

See [usage.md](usage.md) for the Go API + REST endpoints + the two runtime modes.
